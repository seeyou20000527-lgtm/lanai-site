# 辣奶火锅 · 官方小站

> 想让所有粉丝都能打开？看 **[部署指南](README-DEPLOY.md)**（服务器 / 域名 / HTTPS / 备案 / 备份）和 **[GitHub 部署](README-GITHUB.md)**（代码托管 + push 自动上线）。

虚拟主播 **辣奶火锅** 的粉丝站点：简介 / 直播月历 / 物料下载 / 二创投稿 / 使用规则。
零依赖 Node.js，`node server.js` 就能跑；后台用**账号密码**登录，月历、简介、物料、资讯都能自己改。

## 二、启动

需要 **Node.js 18+**（无第三方依赖，不用 `npm install`）。

```bash
cd lanai-huoguo
node server.js          # Windows 也可以双击 start.bat
```

- 前台：<http://127.0.0.1:8787>
- 后台：<http://127.0.0.1:8787/admin>
- 默认账号：**lanai** / 密码：**huoguo2026**（在 `config.json` 里改，**上线前一定改掉**）

> 想用手机/局域网访问，把 `config.json` 的 `host` 改成 `0.0.0.0`。

## 三、后台怎么用

登录后左侧有六个页面：

1. **概览**：待审核数量、已上架数量、物料数、下载总数；右上「正在直播」开关，打开后前台会出现 LIVE 状态。
2. **二创审核**：待审核 / 已上架 / 已拒绝三个分类。
   - 「通过」→ 立刻出现在前台「二创展厅」；
   - 「拒绝」→ 保留记录但不展示；
   - 「删除」→ 记录和条目一起删掉（文件仍留在 uploads）。
3. **月历**：直接改日期、时间、标题、类型、备注，点「保存排期」前台立刻更新；「+ 加一场」新增，默认开播时间 20:30。
4. **公告**：第一条是当前活动（大卡片），其余自动进「往期活动」；可置顶、改、删。
5. **资讯**：首页「最近的事」内容，改完保存。
6. **物料**：上传新文件（自动进 `public/materials/uploads/`），改标题/描述/分类，删除。
7. **歌单**：加歌 / 改歌名、歌手、标签、备注、原曲链接；顶部搜索框可直接找歌，保存后前台立即更新。
8. **图片**：「资料」页的头像 / LOGO / 立绘可以直接上传，上传后拖动 + 缩放裁剪，框里看到的就是最终效果，保存即生效。
9. **音乐**：上传 mp3 / m4a / wav / ogg，填歌名、歌手、BPM（决定 CD 转速）、B 站影片链接、封面、歌词（LRC 格式 `[00:12.30]歌词` 会自动滚动高亮）；已上传的歌也能随时改标题 / 歌手 / 封面 / BPM / 链接 / 歌词。
10. **资料**：名字、口号、简介正文、QQ 群、B 站链接、档案四项、标签、图片路径。

所有修改都写回 `data/` 下的 JSON，随时可以备份。

## 五、改内容

### 换头像 / 立绘 / LOGO

| 文件 | 用途 |
| --- | --- |
| `public/assets/img/avatar.png` | 头像（正方形，512 以上） |
| `public/assets/img/char-bun.png` | 首页立绘（透明底，竖图，会自动裁成 4:5 竖版） |
| `public/assets/img/char-long.png` | 简介立绘 |
| `public/assets/img/logo.png` | 顶栏 / 页脚 LOGO（透明底） |
| `public/assets/img/og.png` | 分享预览图 1200×630 |
| `public/assets/img/favicon.png` | 标签页图标 |

换完直接刷新，不用重启。

### 改排期

后台「月历」直接改；或者编辑 `data/site.json` 的 `schedule`：

```json
{ "date": "2026-11-14", "time": "20:00", "duration": 150,
  "title": "沸腾杂谈 · 本周瓜田大乱炖", "type": "杂谈", "note": "今晚有新品试吃" }
```

`type` 决定日历色块颜色：杂谈 / 歌回 / 游戏 / 活动 / 休息。

### 改物料

后台「物料」上传即可；或把文件丢进 `public/materials/`，在 `site.json` 的 `materials` 里加一条（封面建议 1200×750 / 8:5）。

## 六、上线清单

1. **改密码**：`config.json` → `admin.password`（顺便改 `admin.username`）
2. **改端口**：`config.json` → `port`
3. **开 HTTPS**：后台密码是明文传输，强烈建议套 HTTPS
4. **反代**：Nginx 记得 `client_max_body_size 20m`

```nginx
server {
    listen 80;
    server_name your-domain.com;
    client_max_body_size 20m;
    location / {
        proxy_pass http://127.0.0.1:8787;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

常驻运行：Linux 用 `pm2 start server.js --name lanai`，Windows 用任务计划程序开机跑 `start.bat`。

> Vercel / Netlify / GitHub Pages 只能放纯前端，**登录后台和投稿上传需要 Node 服务**。

## 七、安全说明

- 登录用 **HttpOnly Cookie + 12 小时会话**，密码不落前端
- 登录失败 10 分钟内最多 8 次，防爆破
- 未通过审核的投稿文件，外部访问一律 404（后台登录后可预览）
- 所有上传都限制扩展名与大小，路径做了穿越防护

## 八、素材怎么来的

`tools/` 里的 Python 脚本用 Pillow 生成壁纸、头像包、表情包、OBS 边框、待机画面和全部封面：

```bash
python tools/gen_v2.py          # 立绘裁切 / 头像 / 壁纸 / 表情包 / 边框 / 待机
python tools/gen_covers_v2.py   # 11 张 8:5 物料封面
python tools/gen_og.py          # 分享图
```

改脚本顶部的莫兰迪色值就能换整套配色。
